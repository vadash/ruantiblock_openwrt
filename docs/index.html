Ruantiblock packages for OpenWrt 24.10

This fork publishes architecture-independent packages for OpenWrt 24.10. Add the feed once, then use LuCI or SSH to install and update ruantiblock.

Unsigned personal feed. HTTPS protects the connection, but opkg does not verify a publisher signature. Add this feed only if you trust this repository.

Packages

PackagePurpose
ruantiblockCore service and nftables integration.
luci-app-ruantiblockLuCI web interface. Depends on the core package.
luci-i18n-ruantiblock-ruOptional Russian translation.

The Lua and Python parser modules are not part of this feed.

Option 1: add the feed in LuCI

  1. Open System → Software → Configuration.
  2. Add this line to /etc/opkg/customfeeds.conf: 
    src/gz ruantiblock https://vadash.github.io/ruantiblock_openwrt/24.10/
  3. Save the configuration and refresh the package lists.
  4. Install luci-app-ruantiblock. OpenWrt installs ruantiblock as its dependency.
  5. Optionally install luci-i18n-ruantiblock-ru.

Option 2: add the feed over SSH

cat >> /etc/opkg/customfeeds.conf <<'EOF'
src/gz ruantiblock https://vadash.github.io/ruantiblock_openwrt/24.10/
EOF

opkg update
opkg install luci-app-ruantiblock
opkg install luci-i18n-ruantiblock-ru  # optional

Keep the existing official OpenWrt feeds. They supply dependencies such as dnsmasq-full and kmod-nft-tproxy.

Start the service after a fresh install

/etc/init.d/ruantiblock enable
/etc/init.d/ruantiblock start

No cron job is created. Configure your own update schedule if needed. Package upgrades preserve the service state and existing custom cron entries.

Update

opkg update
opkg upgrade ruantiblock luci-app-ruantiblock

If the translation package is installed, update it too:

opkg upgrade luci-i18n-ruantiblock-ru

Use the targeted commands instead of an unrestricted opkg upgrade, which can update unrelated packages.

Verify

opkg list-installed | grep ruantiblock
/etc/init.d/ruantiblock status

Backup and rollback

Before the first 2.1.12-r5 upgrade, save the current configuration:

mkdir -p /tmp/ruantiblock-backup
cp -a /etc/config/ruantiblock /etc/ruantiblock /tmp/ruantiblock-backup/
[ -f /etc/crontabs/root ] && cp -a /etc/crontabs/root /tmp/ruantiblock-backup/

The feed retains fork-built package files. After a later release exists, replace <previous-version> with that release and install the retained files:

wget -O /tmp/ruantiblock.ipk "https://vadash.github.io/ruantiblock_openwrt/24.10/ruantiblock_<previous-version>_all.ipk"
wget -O /tmp/luci-app-ruantiblock.ipk "https://vadash.github.io/ruantiblock_openwrt/24.10/luci-app-ruantiblock_<previous-version>_all.ipk"
opkg install /tmp/ruantiblock.ipk /tmp/luci-app-ruantiblock.ipk

The first fork release has no earlier fork-built package to restore. Use the configuration backup if you need to return to the upstream installation.
